import ButtonSvelte from "@registry/button/button.svelte";
import ButtonAstro from "@registry/button/button.astro";

The same `Button` is rendered below three times — once per framework. All three import the same `button` config from `apps/docs/registry/Button/Button.tv.ts`, so the visual output is identical.

## Under the hood

- **Shared config:** `apps/docs/registry/Button/Button.tv.ts` — a `tv()` call producing the class string. Colocated with its component.
- **Wrappers:** `apps/docs/registry/Button/Button.{tsx,svelte,astro}` — thin passthroughs that call `button({variant, size})` with `cn()`.
- **Tokens:** `bg-primary`, `bg-destructive`, etc. resolve to `oklch()` values in `apps/docs/registry/all-themes.css` via the `@theme inline` mapping in the docs app's `global.css`.
