import DialogNative from "@registry/dialog/dialog-native.svelte";

The `open` attribute is set in the SSR'd HTML — the dialog is visible before JS loads. When Svelte hydrates it reads `dialogEl.open` and calls `showModal()` without stomping the existing DOM.
