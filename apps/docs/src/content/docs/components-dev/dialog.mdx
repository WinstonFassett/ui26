React and Svelte require a `dialog-machine.*` backend conforming to the shared interface (`dialog-machine.vanilla.ts` ships by default; `dialog-machine.matchina.ts` and `dialog-machine.xstate-fsm.ts` also satisfy the contract). DOM behavior delegates to whichever view is installed — `dialog-radix-ui.tsx` (Radix `DialogPrimitive`), `dialog-bits-ui.svelte` (bits-ui), `dialog-machine-ui.{tsx,svelte}` (own impl), or `dialog-progressive.{tsx,svelte}` (native `<dialog>`).

Trigger and dialog live together. Machine manages open/close transitions and animation timing.

## Distant trigger

Trigger lives outside the component tree. Sets `data-dialog-open="{id}"` on `document.body`. Dialog watches via `MutationObserver` and fires machine events.

## Pre-opened (defaultOpen)

Opens immediately on mount — useful for confirmation screens, onboarding gates, or error states that should block interaction. Shown on its own page to avoid blocking this one: [dialog-default-open](/components/dev/dialog-default-open).

## Dynamic content

Trigger calls `loadContent` before opening. Dialog waits for the promise to resolve, shows a loading state on the button, then opens with the fetched data already rendered.

## SSR'd slot content

The Svelte island owns interaction and transitions. The slot content is server-rendered by Astro — no JS needed to paint it. This is the same pattern as the code block previews.

## Native `<dialog>` (progressive enhancement)

Native `<dialog>` element — Astro SSRs the content into slots, Svelte island wires the machine on mount. No bits-ui, no portal. Focus trap, scroll lock, and Escape handling are browser-native. `::backdrop` replaces the overlay div. Machine reads `dialogEl.open` on mount so hydration never stomps open state.

## Under the hood

- **Machine**: `Closed → Opening → Open → Closing → Closed` — same shape as Popover
- **Effects**: `OpenDialog` (delegate to platform, fire `ready`), `CloseDialog` (no-op — platform owns teardown), `AnimateClose` (wait for CSS animation, then `done`)
- **React effector**: Radix `DialogPrimitive` handles focus trap, portal, scroll lock — machine just reflects open state via `open` prop
- **Svelte effector**: `bits-ui` `Dialog` — same Radix primitives ported to Svelte, `data-state` attributes match React exactly
- **Distant trigger**: `MutationObserver` on `document.body` watching `data-dialog-open` — SSR-safe, zero overhead, no shared bus needed for the 80% case
