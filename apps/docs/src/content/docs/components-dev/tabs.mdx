React and Svelte share one state backend: `tabs.state.ts` (Matchina atom). Astro is SSR-first — prop-driven, plain HTML, vanilla custom element for switching. No framework runtime, no hydration gap, first tab visible without JS.

## Under the hood

- **React:** `useSyncExternalStore` + `createContext` wired to Matchina atom in `tabs.state.ts`.
- **Svelte:** `setContext`/`getContext` with a thin `{ subscribe }` adapter bridging Matchina `StoreChange<T>` to the Svelte store protocol. SSR-correct with `client:load`.
- **Astro:** prop-driven, fully SSR'd, vanilla custom element for switching. Same pattern as `CodeTabs.astro`. No framework runtime.
