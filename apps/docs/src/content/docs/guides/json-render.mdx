`@json-render/react` turns a plain JSON **Spec** into a rendered React tree, using a component registry you provide. ui26 ships a ready-made registry that wires all primitive components — Button, Badge, Card, Field, Alert, and more — to this renderer.

## How it works

A **Spec** is a flat map of element nodes. Each node names a `type` (matched to a registry entry), carries `props`, and lists `children` by key.

```json
{
  "root": "btn",
  "elements": {
    "btn": { "type": "Button", "props": { "label": "Save changes" }, "children": [] }
  }
}
```

The renderer walks the tree from `root`, resolves each `type` through the registry, and passes serialised `props` + resolved `children` to the component. Null props are coerced to `undefined` at the registry boundary so React components stay clean.

## Setup

Install the peer package and import the ui26 registry:

```ts
// registry is pre-built; wire it into JSONUIProvider
import { registry } from "@/components/demos/json-render/registry";
import { Renderer, JSONUIProvider } from "@json-render/react";

export function MyDemo({ spec }) {
  return (
    <JSONUIProvider registry={registry}>
      <Renderer spec={spec} registry={registry} />
    </JSONUIProvider>
  );
}
```

## Supported components

| Type | Props |
|------|-------|
| `Button` | `label`, `variant`, `size`, `disabled` |
| `Badge` | `text`, `variant` |
| `Text` | `content`, `size`, `muted`, `mono`, `className` |
| `Heading` | `text`, `level`, `className` |
| `Stack` | `direction`, `gap`, `align`, `justify`, `wrap`, `className` |
| `Grid` | `cols`, `gap`, `className` |
| `Card` / `CardHeader` / `CardContent` / `CardFooter` | `className` |
| `CardTitle` / `CardDescription` | `text`, `className` |
| `Input` | `id`, `type`, `placeholder`, `value`, `invalid`, `disabled` |
| `Textarea` | `id`, `placeholder`, `value`, `rows`, `invalid`, `disabled` |
| `Checkbox` | `id`, `checked`, `disabled` |
| `Switch` | `id`, `checked`, `disabled` |
| `Label` | `text`, `htmlFor` |
| `Alert` / `AlertTitle` / `AlertDescription` | `variant`, `text`, `className` |
| `Field` / `FieldContent` / `FieldLabel` / `FieldDescription` / `FieldError` | orientation, text, htmlFor |
| `Separator` | `orientation`, `decorative` |
