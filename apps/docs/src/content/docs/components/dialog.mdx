## Controlled mode

Parent owns `open` and `onOpenChange` (React) or uses `bind:open` (Svelte). Internal triggers fire `onOpenChange` instead of mutating internal state — the parent decides whether to honor the request.

</div>

## Distant trigger

The trigger doesn't have to be inside the dialog. Set `data-dialog-open="{id}"` on `document.body` from anywhere — a nav item, a keyboard shortcut, a server action. The dialog watches via `MutationObserver`.

    </DialogSvelte>
  </div>
</div>

## Dynamic content

Pre-fetch data, then flip `open` to `true` once it's ready. The trigger shows a loading state while the promise resolves, then the dialog opens with content already rendered — all via the prop API.
