## Under the hood

- **Shared config:** `apps/docs/registry/Card/Card.tv.ts` — one `tv()` call per subcomponent (card, cardHeader, cardTitle, cardDescription, cardContent, cardFooter). No variants today.
- **Wrappers:** thin `<div>`s in React (one file), Svelte (one file per subcomponent), Astro (one file per subcomponent).
- **Composition:** subcomponents are siblings, not children of a compound parent — same shape as shadcn 2026.
