## Under the hood

- **Shared config:** `registry/_shared/theme/button.ts` — a `tv()` call producing the class string.
- **Wrappers:** `registry/Button/Button.{tsx,svelte,astro}` — thin passthroughs that call `button({variant, size})` with `cn()`.
- **Tokens:** `bg-primary`, `bg-destructive`, etc. resolve to `oklch()` values in `registry/_shared/tokens.css` via the `@theme inline` mapping in the docs app's `global.css`.
