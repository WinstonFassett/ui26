title: Input
description: Dumb, stateless Input primitive. Three wrappers (React, Svelte, Astro) over one shared class config. Error state driven by aria-invalid.
---

import { Input as InputReact } from "@registry/input/input.tsx";
import InputSvelte from "@registry/input/input.svelte";
import InputAstro from "@registry/input/input.astro";

Same `Input` rendered three times per row — React, Svelte, Astro. No `variant` or `size` prop: error state comes from `aria-invalid`, sizing comes from `className`.

## Under the hood

- **Shared config:** `apps/docs/registry/Input/Input.tv.ts` — base classes only, no variants today. Keeping the `tv()` shape means adding `size` or a leading/trailing slot later is a zero-refactor change.
- **Wrappers:** `apps/docs/registry/Input/Input.{tsx,svelte,astro}` — thin passthroughs rendering `<input>`.
- **Error state:** pass `aria-invalid` rather than a prop. Reads as valid HTML, works without JS, surfaces in a11y trees.
