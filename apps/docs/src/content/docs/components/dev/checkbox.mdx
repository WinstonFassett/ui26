## Under the hood

- **Shared config:** `apps/docs/registry/Checkbox/Checkbox.tv.ts` — base classes only, no variants.
- **Wrappers:** `apps/docs/registry/Checkbox/Checkbox.{tsx,svelte,astro}` — thin passthroughs rendering `<input type="checkbox">`.
- **Theming:** `accent-primary` maps the native checkbox color to our primary token — zero custom SVG, browser-native rendering.
- **Error state:** pass `aria-invalid` rather than a prop.
