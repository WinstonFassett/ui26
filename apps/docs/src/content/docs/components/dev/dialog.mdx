React and Svelte share one state machine: `dialog.state.ts` (Matchina). DOM behavior is delegated to the platform — Radix `DialogPrimitive` for React, `bits-ui` `Dialog` for Svelte. Both handle portal, focus trap, scroll lock, and `data-state` animation attributes identically.

## Co-located trigger

Trigger and dialog live together. Machine manages open/close transitions and animation timing.

## Distant trigger

Trigger lives outside the component tree. Sets `data-dialog-open="{id}"` on `document.body`. Dialog watches via `MutationObserver` and fires machine events.

## Under the hood

- **Machine**: `Closed → Opening → Open → Closing → Closed` — same shape as Popover
- **Effects**: `OpenDialog` (delegate to platform, fire `ready`), `CloseDialog` (no-op — platform owns teardown), `AnimateClose` (wait for CSS animation, then `done`)
- **React effector**: Radix `DialogPrimitive` handles focus trap, portal, scroll lock — machine just reflects open state via `open` prop
- **Svelte effector**: `bits-ui` `Dialog` — same Radix primitives ported to Svelte, `data-state` attributes match React exactly
- **Distant trigger**: `MutationObserver` on `document.body` watching `data-dialog-open` — SSR-safe, zero overhead, no shared bus needed for the 80% case
