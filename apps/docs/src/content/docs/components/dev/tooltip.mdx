React and Svelte share one state machine: `tooltip.state.ts` (Matchina). Delay timers (`StartOpenDelay`, `StartCloseDelay`) are declared effects with cleanup — the machine is pure state, the effector owns the `setTimeout`/`clearTimeout`.

## Under the hood

- **Machine**: `Closed → OpenDelay → Opening → Open → CloseDelay → Closing → Closed`
- **Delay effects**: `StartOpenDelay` / `StartCloseDelay` return cleanup functions (`clearTimeout`) — same pattern as `StopPositioner`
- **Hover re-entry**: `enter` in `CloseDelay` short-circuits back to `Open` without re-running the positioner
- **Effector**: same Floating UI effector pattern as Popover — `StartPositioner` / `StopPositioner` / `AnimateClose`
