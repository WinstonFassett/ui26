## Under the hood

- **Machine**: reused `createPopoverMachine()` — no new state needed for open/close
- **Placement**: `bottom-start` instead of `bottom` (left-aligned to trigger)
- **Outside click**: `mousedown` listener registered in the effector, cleaned up on unmount
- **Item selection**: `close` event on click, `onSelect` callback fires before close
- **Keyboard nav**: deferred — follow-up spike
