import { Textarea as TextareaReact } from "@registry/textarea/textarea.tsx";
import TextareaSvelte from "@registry/textarea/textarea.svelte";
import TextareaAstro from "@registry/textarea/textarea.astro";

Same `Textarea` rendered three times per row — React, Svelte, Astro. No `variant` or `size` prop: error state comes from `aria-invalid`, height grows with content via `field-sizing-content`.

## Invalid (`aria-invalid`)

<div class="not-content grid grid-cols-3 gap-3 my-6">
  <TextareaReact aria-invalid="true" defaultValue="too short" client:load />
  <TextareaSvelte aria-invalid={true} value="too short" client:load />
  <TextareaAstro aria-invalid="true">too short</TextareaAstro>
</div>

## Under the hood

- **Shared config:** `apps/docs/registry/Textarea/Textarea.tv.ts` — base classes only, no variants today.
- **Wrappers:** `apps/docs/registry/Textarea/Textarea.{tsx,svelte,astro}` — thin passthroughs rendering `<textarea>`.
- **Auto-grow:** `field-sizing-content` lets the textarea grow with its content without JS.
- **Error state:** pass `aria-invalid` rather than a prop.
