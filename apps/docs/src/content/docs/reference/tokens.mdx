---
title: Design Tokens
description: Core color and radius tokens shared across all ui26 themes.
---

Tokens are defined per-theme as CSS custom properties. They're mapped to Tailwind utilities via `@theme inline` in the global stylesheet. Toggle the theme picker (top-right) to see them switch.
