    <div class="font-serif italic font-medium text-[32px] leading-[1.1] tracking-[-0.015em] text-foreground">Create a theme</div>
    <div class="text-[13px] text-muted-foreground mt-1.5 max-w-[560px] leading-normal">
      Say we're adding <code class="font-mono text-[12px] bg-code border border-border px-1">sunset</code>. The process involves four steps: token blocks, registration, optional fonts, and verification.
    </div>
  </div>

  <div class="space-y-8">
    <div>
      <div class="font-semibold text-[14px] mb-3 text-foreground">1. Add two token blocks</div>
      <p class="text-[13px] text-muted-foreground leading-[1.55] mb-4">
        In <code class="font-mono text-[12px] bg-code border border-border px-1">registry/tokens.css</code>, append:
      </p>

```css
[data-theme="sunset"] {
  /* fonts, radius, shadow vocabulary, light palette */
  --font-sans: "Inter", system-ui, sans-serif;
  --font-serif: ui-serif, Georgia, serif;
  --font-mono: ui-monospace, Menlo, monospace;

  --background: oklch(0.98 0.02 60);
  --foreground: oklch(0.2 0.05 30);
  /* ...the rest of the token contract above */

  --radius: 0.5rem;

  --shadow-color: 30 20 10;
  --shadow-xs: 0 1px 1px rgb(var(--shadow-color) / 0.05);
  /* ...sm/md/lg/highlight-inset */
}

[data-theme="sunset-dark"] {
  /* only what changes for dark */
  --background: oklch(0.14 0.04 30);
  --foreground: oklch(0.96 0.02 60);
  /* ...surfaces + colors that flip; fonts/radius/shadow vocab inherit */
}
```

    <div>
      <div class="font-semibold text-[14px] mb-3 text-foreground">2. Register the theme in two places</div>
      <p class="text-[13px] text-muted-foreground leading-[1.55] mb-4">
        In <code class="font-mono text-[12px] bg-code border border-border px-1">ThemeProvider.astro</code>, add the key to the <code class="font-mono text-[12px] bg-code border border-border px-1">THEMES</code> allowlist inside the inline script:
      </p>

      <div class="border border-border rounded bg-card overflow-hidden mb-4">
        <div class="px-4 py-3 bg-muted">
          <div class="font-mono text-[10px] tracking-[0.06em] uppercase text-text-mute">ThemeProvider.astro</div>
        </div>
        <div class="px-4 py-3">
          <code class="font-mono text-[11px] text-foreground">const THEMES = ['editorial', 'tix', 'shad', 'neon-synthwave', 'cyberpunk-neon', 'sunset'];</code>
        </div>
      </div>

      <p class="text-[13px] text-muted-foreground leading-[1.55] mb-4">
        In <code class="font-mono text-[12px] bg-code border border-border px-1">theme-picker.tsx</code>, add the key to the local <code class="font-mono text-[12px] bg-code border border-border px-1">THEMES</code> array, extend the <code class="font-mono text-[12px] bg-code border border-border px-1">Name</code> union, and add a <code class="font-mono text-[12px] bg-code border border-border px-1">LABELS</code> entry:
      </p>

      <div class="border border-border rounded bg-card overflow-hidden mb-4">
        <div class="px-4 py-3 bg-muted">
          <div class="font-mono text-[10px] tracking-[0.06em] uppercase text-text-mute">theme-picker.tsx</div>
        </div>
        <div class="px-4 py-3">
          <code class="font-mono text-[11px] text-foreground">type Name = 'editorial' | 'tix' | 'shad' | 'neon-synthwave' | 'cyberpunk-neon' | 'sunset';</code>
          <br class="my-2">
          <code class="font-mono text-[11px] text-foreground">const THEMES: readonly Name[] = ['editorial', 'tix', 'shad', 'neon-synthwave', 'cyberpunk-neon', 'sunset'];</code>
          <br class="my-2">
          <code class="font-mono text-[11px] text-foreground">const LABELS: Record&lt;Name, string&gt; = { /* ...existing */ sunset: 'Sunset' };</code>
        </div>
      </div>

      <p class="text-[13px] text-muted-foreground leading-[1.55]">
        Both lists must agree. The pre-paint script uses its copy to reject unknown <code class="font-mono text-[12px] bg-code border border-border px-1">localStorage</code> values; the picker uses its copy to render options.
      </p>
    </div>

    <div>
      <div class="font-semibold text-[14px] mb-3 text-foreground">3. (Optional) Load web fonts</div>
      <p class="text-[13px] text-muted-foreground leading-[1.55]">
        If the theme uses a font not already loaded, add a <code class="font-mono text-[12px] bg-code border border-border px-1">&lt;link&gt;</code> to the <code class="font-mono text-[12px] bg-code border border-border px-1">head</code> array in <code class="font-mono text-[12px] bg-code border border-border px-1">astro.config.mjs</code> alongside the Newsreader/Geist links.
      </p>
    </div>

    <div>
      <div class="font-semibold text-[14px] mb-3 text-foreground">4. Verify</div>
      <p class="text-[13px] text-muted-foreground leading-[1.55] mb-4">From the docs app:</p>
      
      <div class="border border-border rounded bg-card overflow-hidden mb-4">
        <div class="px-4 py-3 bg-muted">
          <div class="font-mono text-[10px] tracking-[0.06em] uppercase text-text-mute">Terminal</div>
        </div>
        <div class="px-4 py-3">
          <code class="font-mono text-[11px] text-foreground">pnpm dev</code>
        </div>
      </div>

      <p class="text-[13px] text-muted-foreground leading-[1.55] mb-4">
        Open a page, pick <code class="font-mono text-[12px] bg-code border border-border px-1">Sunset</code> in the header dropdown, toggle light/dark/auto. Check:
      </p>

      <ul class="text-[13px] text-muted-foreground leading-[1.55] space-y-2 pl-6">
        <li><code class="font-mono text-[11px] bg-code border border-border px-1">document.documentElement.dataset.theme</code> flips between <code class="font-mono text-[11px] bg-code border border-border px-1">sunset</code> and <code class="font-mono text-[11px] bg-code border border-border px-1">sunset-dark</code></li>
        <li><code class="font-mono text-[11px] bg-code border border-border px-1">getComputedStyle(document.documentElement).getPropertyValue('--background')</code> returns your chosen color</li>
        <li>Reloading the page preserves the choice</li>
        <li>Components on <code class="font-mono text-[11px] bg-code border border-border px-1">/kitchen-sink</code> and <code class="font-mono text-[11px] bg-code border border-border px-1">/installs</code> look cohesive</li>
      </ul>

      <p class="text-[13px] text-muted-foreground leading-[1.55] mt-4">
        If a token is missing, you'll see a flash of an unrelated theme's value (the cascade falls through to the previous theme block). Any missing var = missing block entry.
      </p>
    </div>
