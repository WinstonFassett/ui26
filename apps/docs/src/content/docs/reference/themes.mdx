## Model

A **theme** is a full visual identity: palette, typography, radius, shadow vocabulary, border treatment. Light/dark is an axis **within** a theme.

State lives on `<html data-theme>` as a compound key:

| Shape | Example |
|---|---|
| `<name>` | `editorial`, `tix`, `shad` |
| `<name>-dark` | `editorial-dark`, `neon-synthwave-dark` |

One dropdown picks the theme; one toggle picks light/dark/auto. Both write to `localStorage` (`ui26-theme-name`, `ui26-theme-mode`) and to the compound `data-theme` attribute pre-paint.

The default theme is **shad** — its file owns `:root` in addition to `[data-theme="shad"]`, so documents without a `data-theme` attribute render correctly.

## Install

ui26 components don't ship tokens. You install a theme separately, with the standard shadcn CLI — there's no ui26-specific binary.

### Single theme (default `:root` install)

Pick one — it lands as `cssVars` on `:root` (light) and `.dark`. This is the simplest setup and matches shadcn's native single-theme model.

```bash
npx shadcn@latest add https://winston-ui26.netlify.app/r/themes/shad.json
```

Available: `shad`, `editorial`, `tix`, `neon-synthwave`, `cyberpunk-neon`, `pastel-kawaii`, `zen-garden`, `bubblegum-pop`, `retro-arcade`, `tropical-paradise`, `steampunk-cogs`, `space-odyssey`, `vintage-vinyl`, `misty-harbor`.

### Full switcher (all themes via `data-theme`)

Drops every theme as a standalone CSS file under `src/styles/themes/` plus an `all-themes.css` barrel:

```bash
npx shadcn@latest add https://winston-ui26.netlify.app/r/themes.json
```

Then add one line to your global stylesheet:

```css
@import './styles/themes/all-themes.css';
```

Switching themes is now a matter of writing the compound key to `<html data-theme="...">`. Bring your own picker UI, or copy ours from [`apps/docs/src/components/starlight`](https://github.com/WinstonFassett/ui26/tree/main/apps/docs/src/components/starlight).

## Token contract

Every theme block must define (at minimum):

**Surfaces**
`--background` `--foreground` `--card` `--card-foreground` `--popover` `--popover-foreground`

**Anchors**
`--primary` `--primary-foreground` `--secondary` `--secondary-foreground` `--muted` `--muted-foreground` `--accent` `--accent-foreground`

**Feedback**
`--destructive` `--destructive-foreground` `--success` `--warn` `--info` `--purple`

**Structure**
`--border` `--border-soft` `--input` `--ring` `--radius`

**Accent companions / text tiers / code**
`--accent-ink` `--accent-soft` `--text-mute` `--code`

**Shadows** (set to `none` if the theme has none — don't omit)
`--shadow-color` `--shadow-xs` `--shadow-sm` `--shadow-md` `--shadow-lg` `--highlight-inset`

**Fonts** (only if the theme diverges from the default stack)
`--font-sans` `--font-serif` `--font-mono`

The dark block can redefine only what changes. If a value is identical to the light block (typically `--radius`, fonts, or shadow vocabulary), leave it out of `-dark` — it cascades.

## Adding a theme

Say we're adding `sunset`.

### 1. Create the CSS file

Create `src/styles/themes/sunset.css` (or wherever your stylesheets live):

```css
[data-theme="sunset"] {
  --font-sans: "Inter", system-ui, sans-serif;
  --font-serif: ui-serif, Georgia, serif;
  --font-mono: ui-monospace, Menlo, monospace;

  --background: oklch(0.98 0.02 60);
  --foreground: oklch(0.2 0.05 30);
  /* ...full token contract */

  --radius: 0.5rem;

  --shadow-color: 30 20 10;
  --shadow-xs: 0 1px 1px rgb(var(--shadow-color) / 0.05);
  /* ...sm/md/lg/highlight-inset */
}

[data-theme="sunset-dark"] {
  /* only what changes for dark — fonts/radius/shadow vocab inherit */
  --background: oklch(0.14 0.04 30);
  --foreground: oklch(0.96 0.02 60);
  /* ...surfaces + colors that flip */
}
```

### 2. Import it

In your global stylesheet:

```css
@import './themes/sunset.css';
```

### 3. Activate

Set `data-theme` on `<html>` to switch to it:

```html
<html data-theme="sunset">
```

For dark: `data-theme="sunset-dark"`. That's it.

### Picker UI (optional)

If you want a theme switcher like the one in these docs, copy [`ThemeProvider.astro`](https://github.com/WinstonFassett/ui26/tree/main/apps/docs/src/components/starlight/ThemeProvider.astro) and [`theme-picker.tsx`](https://github.com/WinstonFassett/ui26/tree/main/apps/docs/src/components/starlight/theme-picker.tsx) into your project and add your theme key to the `THEMES` array in each file.
